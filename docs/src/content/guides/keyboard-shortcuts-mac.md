Blankie for Mac was designed to be keyboard friendly for both power users and people who rely on accessibility tools like [VoiceOver](https://support.apple.com/guide/voiceover/get-started-vo4be8816d70/mac) and [Full Keyboard Access](https://support.apple.com/guide/mac-help/use-full-keyboard-access-mchlc06d1059/mac). The core actions all have shortcuts. Here's the full list. It also lives inside the app under **Help → Keyboard Shortcuts** if you'd rather keep it close.

## The shortcuts

| Shortcut | Action |
| --- | --- |
| {{kbd:⌘ I}} | Import a sound or .blankie preset file |
| {{kbd:⌘ E}} | Export the current preset as a .blankie file |
| {{kbd:⌘ O}} | Open Manage Sounds |
| {{kbd:⌘ ,}} | Open Settings |
| {{kbd:⌘ S}} | Show or hide the sidebar |
| {{kbd:⌘ N}} | New window |
| {{kbd:⌘ ⇧ ?}} | Show the Keyboard Shortcuts panel |
| {{kbd:⌘ W}} | Close window |
| {{kbd:⌘ Q}} | Quit Blankie |
| {{kbd:Esc}} | Close the current sheet |
| {{kbd:Tab}} / {{kbd:⇧ Tab}} | Focus the next or previous sound in the preset |
| {{kbd:Space}} / {{kbd:Enter}} | Toggle play or pause for the focused sound |
| {{kbd:↑}} / {{kbd:↓}} | Raise or lower the focused sound's volume |

Your keyboard's **play/pause media key** works here too, the same way it does in a music app. For all the other ways to start and stop without touching the window, see [Control Blankie from Anywhere](/guides/control-blankie-anywhere/).

## A couple of things worth knowing

- {{kbd:⌘ S}} toggles the sidebar, not "save." Blankie saves [preset changes automatically](/guides/create-and-manage-presets/), so that old save shortcut was sitting there unused and I gave it a better job.
- {{kbd:⌘ I}} is the quickest way to a new sound. Press it, pick a file, give it a name, and you're done. That same shortcut also opens any [.blankie preset file](/guides/share-presets/) a friend has sent you.
