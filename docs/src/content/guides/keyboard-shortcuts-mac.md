Blankie for Mac was designed to be keyboard friendly for both power users and people who rely on accessibility tools like [VoiceOver](https://support.apple.com/guide/voiceover/get-started-vo4be8816d70/mac) and [Full Keyboard Access](https://support.apple.com/guide/mac-help/use-full-keyboard-access-mchlc06d1059/mac). The core actions all have shortcuts. Here's the full list, but you can also find it inside the app under **Help → Keyboard Shortcuts**.

## The shortcuts

| Shortcut | Action |
| --- | --- |
| {{kbd:⌘ I}} | Import a sound or .blankie preset file |
| {{kbd:⌘ E}} | Export the current preset as a .blankie file |
| {{kbd:⌘ O}} | Open Manage Sounds |
| {{kbd:⌘ ,}} | Open Settings |
| {{kbd:⌘ S}} | Show or hide the sidebar |
| {{kbd:⌘ N}} | New window |
| {{kbd:⌘ ⇧ ?}} | Show the Keyboard Shortcuts panel |
| {{kbd:⌘ W}} | Close window |
| {{kbd:⌘ Q}} | Quit Blankie |
| {{kbd:Space}} | Play or pause (all of Blankie or a focused sound) |
| {{kbd:⌘ →}} / {{kbd:⌘ ←}} | Jump to the next or previous favorite |
| {{kbd:⌘ ↑}} / {{kbd:⌘ ↓}} | Raise or lower the overall volume |
| {{kbdicon:play-pause}} | Play or pause your whole mix (media key) |
| {{kbdicon:rewind}} / {{kbdicon:fast-forward}} | Jump to the previous or next favorite (media keys) |
| {{kbd:Esc}} | Close the current sheet / Exit Keyboard Focus |
| {{kbd:Tab}} / {{kbd:⇧ Tab}} | Focus the next or previous sound in the preset |
| {{kbd:Enter}} | Toggle the focused sound on or off |
| {{kbd:↑}} / {{kbd:↓}} | Raise or lower the focused sound's volume |

{{kbd:Space}} starts and stops your whole mix, just like other media apps, with one exception: if a single sound tile has keyboard focus (the sound has a white ring around it), {{kbd:Space}} toggles just that single sound (the same as clicking a sound). To exit keyboard focus, press {{kbd:Esc}} and then {{kbd:Space}} will control Play/Pause for the entire Blankie app again. For all the other ways to start and stop without touching the window, see [Control Blankie from Anywhere](/guides/control-blankie-anywhere/).

## A couple of things worth knowing

- These shortcut keys work only while Blankie is your active/focused app. Blankie doesn't claim any system-wide hotkeys, so if you're off in another app, reach for your keyboard's media keys, the menubar icon, or [Control Center](/guides/control-blankie-anywhere/) to manage your mix.
- {{kbd:⌘ S}} toggles the sidebar, it does not "save." Blankie saves all [preset changes instantly and automatically](/guides/create-and-manage-presets/).
- {{kbd:⌘ I}} is the quickest way to import a sound, or to open a [.blankie preset file](/guides/share-presets/) a friend has sent you.
- {{kbd:⌘ →}} and {{kbd:⌘ ←}} step through your [favorites](/guides/create-and-manage-presets/) in sidebar order. Your {{kbdicon:rewind}} and {{kbdicon:fast-forward}} media keys, headphone controls, and Control Center all move through the same list.
