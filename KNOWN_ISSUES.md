# Known Blankie iOS Bugs

- When you activate a sound for solo mode, sometimes when you end solo mode, the sound does not stop playing. Sometimes it does, sometimes it doesn't. Sometimes it continues to play with the preset that was previously playing even though it's not part of that preset, and then if you hit pause on the preset, it stops all sounds except the soloed sound.

- Presets can suddenly restart if they are reactivated by something. For example, if you're listening to a preset and then CarPlay is activated, if you go to the Bkankie carplay app it might cause the currently playing preset to be reactivated, causing sounds to change position as if you had just started the preset from not playing (ie sounds that are supposed to start the beginning restart, and sounds that are supposed to start randomly jump to a new position). This seems to happen when the app is backgrounded and then foregrounded again, or when CarPlay is activated.

- The new sound import button should be available from the sounds screen.

- You should be able to choose a new theme color per preset.

- You should be able to change appearance settings (light/dark/system) in settings.

- You should be able to change the default theme color for new presets / app UI without a defined theme color in settings.
